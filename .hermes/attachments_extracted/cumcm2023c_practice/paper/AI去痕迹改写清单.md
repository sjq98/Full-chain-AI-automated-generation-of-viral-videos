# AI 痕迹去除 · 论文手操作手册

> 目标:论文读起来像"三个人七十二小时赶出来的",不像"一个模型五分钟生成的"。

---

## 一、为什么会被查出来

AIGC 检测器(知网、维普、万方、PaperPass)看的是**文本统计特征**:

- **句长规律**:AI 生成的句子长度均匀(平均20-35字,方差小),人写的长短混杂
- **用词分布**:AI 爱用书面连接词(首先/此外/综上所述),词汇"太均衡",缺少口语残留和个人习惯词
- **信息密度**:AI 善于概括,不善给细节——具体数字、中间过程、失败的尝试,人类写作天然带有
- **逻辑顺滑度**:AI 段落"起承转合"太完美,人类写作有跳跃、有补丁

一句话:**AI 文本像流水线上出来的产品,人类文本像手工活——有毛刺。**

## 二、总体策略:分层写作

| 层 | 谁做 | 内容 |
|----|------|------|
| 素材层 | AI(我) | 结构骨架、数据表格、公式推导、图表、参考资料 |
| 组织层 | 论文手 | 段落顺序、论证逻辑、详略取舍 |
| **语言层** | **论文手(必须人写)** | 每个自然段的句子本身 |

铁律:**最终成稿里,每个自然段至少1-2句是你在理解内容后自己写的。** AI 素材可以改写到面目全非,但不能原样粘贴超过一个自然段。

## 三、高频 AI 词替换表

| ❌ AI 高频表达 | ✅ 人类化替代 |
|---|---|
| 值得注意的是 / 值得一提的是 | 直接删掉,或"需要特别说明的是"(全文≤2次) |
| 首先…其次…最后 | 只在真步骤时用"第一步/第二步";否则用自然衔接("先看价格端…再看销量端") |
| 综上所述 / 总而言之 | "综合以上分析"(全文≤2次) |
| 本文建立了XX模型 | "我们采用XX"、"本文以XX为主线" |
| 显著的 / 明显的 | 换成数字:"提升约12%"、"误差下降0.3个百分点" |
| 不仅…而且… | 拆成两句 |
| 针对XX问题,本文提出 | 摘要可用一次,正文避免 |
| 在XX方面具有较好的性能 | 写具体:误差、收敛步数、适用条件 |
| 随着…的发展 / 近年来 | 开头禁用这种 AI 开场白 |
| 有效提升了 / 极大改善了 | 中性描述+数字 |
| 综上所述,该模型具有较好的实用性和推广价值 | 删。写真实缺点 |

## 四、句式手术(每章写完做一遍)

1. **长短句交错**:一段内 1-2 个长句(30字以上)+ 2-3 个短句(15字以内)。"这一步是必要的。""结果并不意外。"这种短句人类感极强。
2. **加入过程感**:写你们怎么做的,包括失败的尝试。"最初用线性回归拟合,残差明显随销量增大而发散,改用对数变换后收敛。"
3. **加入中间数字**:迭代次数、参数取值、p值、误差值、删了多少异常值——细节是人类的指纹。
4. **破坏对称**:模型优缺点不要正好各3条、每条字数相等;让优点2条缺点1条,或者长短不一。
5. **"我们"的使用**:适当用第一人称复数,但别每段都出现;正式描述(公式、假设)用无人称。

## 五、数模论文的 AI 重灾区(重点排查)

| 位置 | AI 特征 | 处理办法 |
|---|---|---|
| **摘要** | 四句结构太工整、每句都"完美" | 允许一处不那么顺的过渡;数字必须具体;结尾别写"具有较高的实用价值"这种空话 |
| **模型评价** | 优缺点高度套路("模型简洁、可操作性强,但未考虑…") | 结合真实过程写:求解慢、假设强、某品类数据稀疏拟合差 |
| **问题四(开放题)** | 写得太全面太官方,像咨询报告 | 保留你们真实的选择排序(比如"优先采集客流数据,因为…"),观点要有一致性 |
| **图表** | 默认 matplotlib 样式(蓝圈、无中文、无单位) | 统一配色、中文标签、坐标轴单位、图注完整;图在文中有引用 |
| **附录代码** | AI 一键生成、注释风格统一得可疑 | 注释写人话,允许有个人命名习惯;代码能跑通是底线 |

## 六、流程管理(防查重与防 AIGC)

1. **留过程稿**:每次修改另存版本(v1/v2/v3),支撑材料里附一份简短的工作日志(哪天做了啥),这是原创性的硬证据
2. **支撑材料**清单:全部源码 + 中间结果表 + 主要图表 + 工作日志
3. **提交前自查**:把终稿丢进 AIGC 检测工具(知网/维普/PaperPass 任选)跑一遍,标红比例高的段落逐段重写
4. **查重提醒**:正文引用题目原句不要超过一句;问题重述必须改写,不能抄题

## 七、改写示例

**AI 味版本:**
> 值得注意的是,不同品类的销量分布存在显著差异。花叶类蔬菜的日均销量明显高于其他品类,而食用菌类的销量波动较大。综上所述,品类间的销量差异为后续定价策略的制定提供了重要依据。

**人类化版本:**
> 六个品类的销量量级差异很大。花叶类日均销量接近 xxx 千克,几乎是食用菌类的 xx 倍;食用菌类标准差与均值相当,波动最剧烈。后面定价时,这两类必须区别对待——走量品类的价格弹性空间小,高波动品类则需要更保守的补货。(数字 xxx 换成真实统计值)

> 对比可见:人类版本有具体数字、有判断、有"后面定价时"这种前后呼应,句长参差。这就是要的效果。
