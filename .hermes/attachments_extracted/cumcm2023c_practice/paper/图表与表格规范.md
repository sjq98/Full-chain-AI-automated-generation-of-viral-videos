# 图表与表格规范(队友出图/出表前必读)

> 用途:全队所有图、表必须按本规范产出,论文手直接嵌入,禁止返工。
> 原则:图注、表题、编号、单位、引用,五件套缺一不可。

---

## 一、图表编号规则

- 图按出现顺序编号:**图1、图2、图3…**(全文连续,不分章节)
- 表按出现顺序编号:**表1、表2、表3…**
- 论文中必须先引用再出现:"如图3所示" → 图3才出现;禁止出现未被引用的图/表
- 公式编号:(1)(2)(3)… 全文连续,引用时写"式(5)"

## 二、图片规范

| 项目 | 要求 |
|------|------|
| 格式 | PNG,分辨率 ≥150dpi(优先 300dpi) |
| 图注 | 图下方居中,宋体小五(9pt),格式:"图1 各品类2020-2023年销量分布箱线图" |
| 坐标轴 | 必须有中文标签 + 单位,如"销量(千克)""日期";刻度清晰 |
| 字体 | 图中文字统一用 微软雅黑/SimHei,字号不小于8pt |
| 配色 | 统一用团队色板(见下),同一张图内对比色不超5种 |
| 线条 | 数据线 1.5-2pt;网格线 0.5pt 虚线 #CCCCCC |
| 图例 | 有多个系列必须加图例,位置不遮挡数据 |

**团队色板**(全队统一,避免每张图一个风格):
- 主色 #2F5597(蓝) #C55A11(橙) #548235(绿) #7030A0(紫) #C00000(红) #595959(灰)

**matplotlib 中文字体设置**(每个脚本开头加):
```python
import matplotlib
matplotlib.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']
matplotlib.rcParams['axes.unicode_minus'] = False
```

## 三、表格规范

| 项目 | 要求 |
|------|------|
| 表题 | 表**上方**居中,宋体小五:"表2 各品类未来一周日补货总量(千克)" |
| 格式 | **三线表**:顶线1.5pt、栏目线0.75pt、底线1.5pt,无竖线 |
| 数字 | 右对齐,保留2位小数;单位写在表头("补货量(千克)"),不写进单元格 |
| 空值 | 用"—"表示,不用"NaN" |
| 长表 | 超过一页的表拆成子表或放附录,正文放精简版 |

**三线表实现**(Word:表格→边框→自定义,只留上下和栏目线;LaTeX:booktabs 宏包的 \toprule \midrule \bottomrule)
